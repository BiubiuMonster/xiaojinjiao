# 小金角

一个 Windows 桌面角标账本：把上班时间按薪资换算成"实时收益"，用愿望碎片衡量离想买的东西还有多远，并把日常支出从当日收益里扣除，生成日账单与月账单。

## 功能

- **桌面角标**：启动后只在屏幕右上角显示一个常驻小卡片，实时显示今日收益，可直接开始/结束赚钱。
  - `↗` 展开完整主界面，主界面点"收起到角标"折回。
  - `—` 收进右下角系统托盘；双击托盘图标或点托盘菜单"唤出角标"即可恢复。
  - `◐` 点击循环切换透明度（100% / 85% / 70% / 50% / 30%），右键菜单与托盘菜单也可精确选择。
  - 右键角标可切换停靠到左上、左下、右下角或退出。
- **收入设置**：自定义月薪、工作制（双休 / 单休 / 上四休三）、上下班时间。
- **计时赚钱**：点"开始赚钱"才计费；忘记点时可设置补填开始时间；收益只在工作时段与工作日累计，每天最多计入一个日薪。
- **工作日历**：内置国务院 2025、2026 放假与调休安排，自动算出每月工作日和日薪；可手动点击日期校正。
- **愿望清单**：填入想买的东西与价格，实时显示今日收益相当于多少个"碎片"及完成百分比。
- **账本**：记录支出并自动从当天收益扣除，展示今日/月账单与明细。

数据保存在本机：Electron 环境下写入 `%APPDATA%/小金角/ledger-data.json`，旧版 `salary-ledger` 目录下的数据会自动读取；浏览器环境下写入 localStorage。

## 开发与运行

```bash
npm install
npm run build     # 构建前端到 dist/
npm start         # 用 Electron 启动应用
```

开发模式（前端热更新 + Electron）：

```bash
npm run dev
# 新开一个终端
set VITE_DEV_SERVER_URL=http://localhost:5173 && npm start
```

## 打包成 Windows exe

```bash
npm run package        # 生成 NSIS 安装包 + 便携版 exe，输出到 release/
npm run package:dir    # 仅生成免安装的目录版本
```

首次打包 Electron/electron-builder 会联网下载二进制文件，请保持网络畅通。

## 计薪口径说明

- 日薪 = 月薪 ÷ 当月工作日数（工作日 = 按工作制 + 法定节假日/调休计算，可在设置中手动覆盖）。
- 每分钟薪资 = 日薪 ÷（标准工时 × 60）。标准工时默认 8 小时，可修改。
- 实时收益 = 每分钟薪资 × 有效计薪分钟数。有效分钟只统计工作日、且不落在午休时段内的部分。
- 上班弹性：在"上班时间 + 弹性分钟"内点开始，视为从上班时间开始计薪；迟到超出弹性部分按实际打卡时间扣减。
- 下班弹性：计薪窗口从下班时间向后延长"弹性分钟"，因此下班后这段时间内结束仍按实际时间计薪（当天总收益封顶一个日薪）。
- 示例：9:00 上班、弹性 30 分、午休 12:00–13:30、18:30 下班、弹性 30 分、8 小时制 → 标准全天净计薪 480 分钟，恰好拿满一个日薪。
- 未记录的工作日默认按全天日薪计入月收入，可在设置中关闭。
